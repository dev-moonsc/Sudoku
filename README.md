# Sudoku

> 프로그램설계방법론 과목의 팀 프로젝트로 제작한 Java Swing 기반 스도쿠 게임입니다.

## 소개

Java Swing GUI로 만든 데스크톱 스도쿠 게임입니다. 난이도를 선택해 무작위로 생성된 스도쿠 퍼즐을 풀고, 클리어 기록을 저장해 난이도별 랭킹을 확인할 수 있습니다.

## 주요 기능

- **난이도 선택**: Easy (빈칸 40개) / Normal (빈칸 50개) / Hard (빈칸 60개)
- **무작위 퍼즐 생성**: 완성된 보드를 셔플·전치해 매번 다른 정답 보드를 만들고, 무작위로 빈칸을 뚫어 퍼즐을 생성
- **정답 검증**: 모든 칸이 채워지면 정답 여부를 확인하고, 오답이 있으면 다시 풀도록 안내
- **랭킹**: 클리어 시 소요 시간과 이름을 입력받아 기록을 저장하고, 난이도별 랭킹을 조회
- **기록 저장**: 게임 기록을 `record.csv` 파일에 영구 저장

## 기술 스택

- Java, Swing (GUI)

## 실행 방법

```bash
cd src
javac -d ../out *.java
java -cp ../out SudokuManager
```

> **참고**: jar로 빌드해 실행 파일을 탐색기에서 더블 클릭으로 실행할 경우, 리소스 파일인 `record.csv`가 간헐적으로 생성되지 않는 현상이 있습니다. 터미널에서 `java -jar` 명령으로
> 실행하면 정상 동작합니다.
